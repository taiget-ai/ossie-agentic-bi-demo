# 分析功能使用说明

右上角可切换中文 / English，页面保存语言偏好，不保存模型密钥。

## 期间对比

点击“比较期间”。默认比较最近两个完整月份，也可以填写两组开始、结束日期。
选择总投注额、净收入或总充值额等可加指标，以及国家或兼容的游戏类别维度。
总变化量由全部分组计算，Top N 只影响显示，其余分组变化单独列出。
变化率的基数为零时显示 NULL；贡献率为分组变化除以净变化，可能为负或超过 100%。
比率和去重人数不能直接做加性贡献分解。结果只说明变化构成，不推断业务原因。

## 指标口径

执行查询后，点击结果中的指标数值。面板显示公式、来源字段、时间字段和去重方式。
人均投注额展示当前范围内的真实投注额与去重人数。解释查询会重新读取当前数据。

## 下钻

点击某个结果行的“下钻”，选择下一层维度。月份会转换为对应日期范围，
并与原日期范围取交集；已选国家等条件保留。顶部导航可返回前一级结果。
充值额没有游戏类别关系，因此包含充值额的查询不会提供可用的游戏类别下钻。
NULL 分组暂不支持等值下钻。

## 模型变更

选择当前查询中的一个指标，编辑候选公式，点击“预览变化”。
原公式与候选公式在同一数据库事务快照上执行，显示各分组差额和两个模型指纹。
此版本一次比较一个指标公式，不覆盖 YAML 文件；查询 limit 不截断比较范围。

## 复现包

点击“导出查询复现包”。导出时重新执行当前结构化查询，并在同一快照读取模型表数据。
ZIP 包含请求、模型、指纹、SQL、参数、JSON/CSV 结果、源数据 JSON 和 replay.py。
解压后执行 `python replay.py`，脚本在内存数据库重建数据并核对结果。
DuckDB 包需要安装 duckdb，SQLite 包使用 Python 标准库。包中包含源数据行，不包含 API 密钥。

## 排序与多选

```json
{
  "metrics": ["total_stake"],
  "dimensions": ["country"],
  "filters": {"country": ["US", "JP", "FI"]},
  "order_by": [{"field": "total_stake", "direction": "desc"}],
  "limit": 5
}
```

离线中文示例：`按月统计总投注额和总充值额`、`最近30天总投注额前5国家`。
离线模式使用有限词汇和规则，复杂自然语言可选择模型理解模式。
